# java-lotto-precourse

## 구현 기능 목록

**1. 로또 구입 금액 입력 기능 추가**
- 1,000원 단위로 입력
- 로또 1장의 가격은 1,000원
- 입력한 구매 금액이 정수형이 아닌 경우 예외 처리
- 입력한 구매 금액이 양수가 아닌 경우 예외 처리
- 입력한 구매 금액이 1,000으로 나누어 떨어지지 않는 경우 예외 처리

**2. 당첨 번호 입력 기능 추가**
- 1~45 범위에서 중복되지 않는 6개 정수 입력
- 번호는 쉼표(,)를 기준으로 구분
- 빈 값이 존재하면 예외 처리
- 정수가 아닌 값이 있으면 예외 처리
- 6개가 아닌 값이 입력되면 예외 처리
- 범위를 벗어나는 숫자가 있으면 예외 처리
- 중복되는 숫자가 있으면 예외 처리

**3. 보너스 번호 입력 기능 추가**
- 1~45 범위에서 당첨 번호와 중복되지 않는 1개 정수 입력
- 정수가 아닌 값 예외 처리
- 범위를 벗어나는 숫자 예외 처리
- 당첨 번호와 중복되는 숫자 예외 처리

**4. 로또 발행 기능 추가**
- 1~45 범위에서 중복되지 않는 6개 정수를 무작위로 추출한 List 생성 (개별 로또)
- List는 오름차순으로 정렬 (개별 로또)
- 구입한 로또 개수만큼 개별 로또 List를 요소로 갖는 List 생성 (전체 로또)

**5. 당첨 여부 및 등수 확인 기능 추가**
- 구입한 로또 번호를 당첨 번호와 비교해 당첨 번호, 보너스 번호 각각과 일치하는 숫자 개수 확인 (개별 로또)
- 일치하는 숫자 개수를 이용해 등수 확인 (개별 로또)
- 각 등수별 당첨 개수 확인 (전체 로또)

**6. 로또 수익률 계산 기능 추가**
- 각 등수별 당첨 개수로부터 전체 당첨 금액 계산
- 전체 당첨 금액을 구입 금액으로 나누어 수익률 계산

**7. 형식에 맞는 출력 기능 추가**
- 구입 금액 입력 시 구매한 로또 번호를 출력
- 당첨 통계 출력

## 기능 요구 사항

간단한 로또 발매기를 구현한다.

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
- 1등: 6개 번호 일치 / 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
- 3등: 5개 번호 일치 / 1,500,000원
- 4등: 4개 번호 일치 / 50,000원
- 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
  - Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.

 ## 입출력 요구 사항
 
 **입력**
- 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
- 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.
- 보너스 번호를 입력 받는다.

**출력**
- 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.
- 당첨 내역을 출력한다.
- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)
- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
