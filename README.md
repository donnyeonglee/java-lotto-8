## 구현 기능 목록

**1. 로또 구입 금액 입력 기능 추가**
- 1,000원 단위로 입력
- 로또 1장의 가격은 1,000원
- 1,000원 단위로 나누어 떨어지지 않는 경우 예외 처리
- 입력 예외 상황 : 정수 자료형이 아닌 경우, 양수가 아닌 경우, 1,000으로 나누어 떨어지지 않는 경우

**2. 당첨 번호 입력 기능 추가**
- 1~45 범위에서 중복되지 않는 6개 정수 입력
- 번호는 쉼표(,)를 기준으로 구분
- 7개 이상의 값이 입력되면 예외 처리
- 중복되는 숫자가 있으면 예외 처리
- 범위를 벗어나는 숫자가 있으면 예외 처리
- 정수가 아닌 값이 있으면 예외 처리

**3. 보너스 번호 입력 기능 추가**
- 1~45 범위에서 당첨 번호와 중복되지 않는 1개 정수 입력
- 범위를 벗어나는 숫자 예외 처리
- 당첨 번호와 중복되는 숫자 예외 처리
- 정수가 아닌 값 예외 처리

**4. 로또 발행 기능 추가**
- 1~45 범위에서 중복되지 않는 6개 정수를 무작위로 추출한 List 생성
- List는 오름차순으로 정렬
